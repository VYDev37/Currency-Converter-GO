## Currency Converter in Golang
Description: Only a simple currency converter made in Golang for learning purpose.

## Which part does this cover?
- [x] API Fetching
- [x] More about input flags
- [x] More about parsing and writing JSON
- [x] Expiration and caching

## How to run
- Run the app with command: `go run . --convert -from [base_currency_id] -to [target_currency_id] -amount [amount]`
- Example: `go run . --convert -from usd -to idr -amount 100`

Note: There'll be three versions of this project.
## Versions:
- Command Line Interface (CLI) (Current branch)
- Terminal User Interface (TUI) 
- Backend of Website / API
